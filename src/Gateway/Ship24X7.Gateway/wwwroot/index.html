🚢 Ship24X7 API Gateway

Unified API Gateway for Ship24X7 Microservices Platform

● Running on Port 8000

📡 Gateway Information

This API Gateway routes requests to the following microservices:

Base URL: http://localhost:8000

All API requests should be made through this gateway for:

  • Unified authentication and authorization
  • Rate limiting and throttling
  • Request/response logging
  • Circuit breaker and retry policies
  • CORS handling
🔐
Auth Service
User authentication, JWT tokens, MFA, OAuth
/api/v1/auth/*
Direct Swagger
📦
Shipment Service
Shipment booking, rate calculation, pickup scheduling
/api/v1/shipments/*
Direct Swagger
📍
Tracking Service

/api/v1/tracking/*
Direct Swagger
📧
Notification Service
Email and SMS notifications, templates

Direct Swagger
💳
Payment Service
Razorpay integration, payment verification, refunds

Direct Swagger

🔧 Gateway Endpoints

GET /health - Health check endpoint
GET /metrics - Prometheus metrics

📚 How to Use

Option 1: Through Gateway (Recommended for Production)

curl http://localhost:8000/api/v1/auth/login

Option 2: Direct to Service (Development Only)

curl http://localhost:9001/api/v1/auth/login

Note: In production, only the gateway should be exposed. Direct service access should be blocked by firewall rules.
